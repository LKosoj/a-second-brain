# Направления

Список `directions` в начале этой заметки можно редактировать без изменения кода.
У записи может быть несколько направлений.
Например, «учусь писать статьи для своего блога» относится к обучению и блогу.

- Здоровье — сон, спорт, самочувствие.
- Семья и отношения — близкие, совместные планы.
- Личные финансы — бюджет, накопления, крупные покупки.
- Дом и быт — жильё, ремонт, повседневные дела.
- Отдых и увлечения — путешествия, хобби, досуг.

«Проекты» — одно из направлений. Конкретный проект имеет отдельную основную
карточку; люди, решения и знания связываются с ней по содержанию записи.
Тип карточки и направление деятельности назначаются независимо.

## Места хранения

| Направление | Основное место хранения |
| --- | --- |
| работа | `business/` — рабочий контекст; карточки проектов — `compiled/projects/` |
| обучение | `thoughts/learnings/` |
| блог | `thoughts/` — заметки по типу: идеи, проекты, знания |
| собственный бизнес | `business/` — контекст бизнеса; карточки проектов — `compiled/projects/` |
| проекты | `compiled/projects/` — основные карточки; `projects/` — справочник |
| здоровье | `health/` |
| семья и отношения | `family/` |
| личные финансы | `finances/` |
| дом и быт | `home/` |
| отдых и увлечения | `hobbies/` |

Выбирай одно основное место по содержанию записи, а направления указывай все
подтверждённые. Один факт сохраняется в одном месте; из других разделов ведут
ссылки. Личный опыт относится к личным разделам; статья чужого автора о здоровье
или деньгах обычно относится к обучению. Рабочий бюджет не является личными
финансами. `private/` заполняется только по явному запросу владельца.
