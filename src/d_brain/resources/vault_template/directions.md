# Направления

Список `directions` в начале этой заметки можно редактировать без изменения кода.
У записи может быть несколько направлений.
Например, «учусь писать статьи для своего блога» относится к обучению и блогу.

- Здоровье — сон, спорт, самочувствие.
- Семья и отношения — близкие, совместные планы.
- Личные финансы — бюджет, накопления, крупные покупки.
- Дом и быт — жильё, ремонт, повседневные дела.
- Отдых и увлечения — путешествия, хобби, досуг.

«Проекты» — одно из направлений. Конкретный проект имеет отдельную основную
карточку; люди, решения и знания связываются с ней по содержанию записи.
Тип карточки и направление деятельности назначаются независимо.
