# Multi-Agent Brainstorm

Запускает параллельные субагенты через `sessions_spawn` — каждый применяет свою методологию мозгового штурма, затем финальный субагент синтезирует результаты в единый отчёт.

## Когда использовать

- Пользователь просит провести мозговой штурм / брейншторм / ideation
- Нужен анализ темы с разных точек зрения
- Задача требует креативных и аналитических подходов одновременно

## Быстрый старт

### 1. Определи тему и пресет

Спроси или выведи из контекста:
- **Тема** — формулировка для штурма
- **Пресет** — набор методологий

| Пресет | Методологии | Когда |
|--------|-------------|-------|
| `all` (по умолчанию) | Все 6 | Максимально широкий охват |
| `creative` | Big Mind Mapping, SCAMPER, Role Storming | Генерация идей |
| `analytical` | Six Thinking Hats, Starbursting | Глубокий анализ |
| `problem_solving` | Reverse Brainstorming, SCAMPER | Решение конкретной проблемы |

### 2. Запусти субагенты параллельно

Для каждой выбранной методологии запусти **один субагент** через `sessions_spawn`. Все запускаются параллельно (одним блоком вызовов, без yield между ними).

**Шаблон промпта для каждого субагента:**

```
Ты эксперт по методологии «{METHOD_NAME}».

{SYSTEM_PROMPT из methodologies.md}

Тема для мозгового штурма:
{TOPIC}

Примени методологию «{METHOD_NAME}» для всестороннего анализа этой темы.
Будь креативен, глубок и практичен.

Верни ТОЛЬКО результат анализа в Markdown — без вводных фраз, без повторения задания.
Отвечай на русском языке.
```

**Параметры sessions_spawn:**
- `task`: промпт с методологией
- `model`: `"light"` (достаточно для одной методологии)
- `mode`: `"run"` (одноразовая задача)
- `label`: название методологии (для отслеживания)

### 3. Дождись результатов и собери

После `sessions_yield` все субагенты вернут результаты. Собери их.

### 4. Запусти синтезирующий субагент

Собрав все результаты, запусти **один финальный субагент**:

```
Ты эксперт по синтезу идей и стратегическому мышлению.

Тема мозгового штурма: {TOPIC}

Ниже результаты мозгового штурма по различным методологиям:

===== МЕТОДОЛОГИЯ 1: {name} =====
{result_1}

===== МЕТОДОЛОГИЯ 2: {name} =====
{result_2}

...

Создай ИТОГОВЫЙ СИНТЕЗИРОВАННЫЙ ОТЧЁТ:

1. **Исполнительное резюме** — ключевые инсайты из всех методологий
2. **Топ-10 лучших идей** — самые ценные идеи со всех подходов
3. **Анализ по категориям**:
   - Стратегические решения
   - Тактические решения
   - Инновационные подходы
   - Риски и ограничения
4. **План действий** — приоритизированные шаги
5. **Рекомендации**
6. **Матрица решений** — сравнительный анализ идей

Принципы:
- Объединяй схожие идеи, устраняй дубликаты
- Выделяй уникальные инсайты каждой методологии
- Приоритизируй практичность
- Формат: чёткий, структурированный, профессиональный, на русском языке
```

**Параметры финального spawn:**
- `model`: `"high"` (для качественного синтеза)
- `mode`: `"run"`
- `label`: `"Синтез брейншторма"`

### 5. Покажи результат

Выведи финальный отчёт пользователю. При необходимости предложи сохранить в файл.

## Пример запуска (пресет `creative`, 3 методологии)

**Шаг 1 — параллельный запуск 3 субагентов:**

Вызови `sessions_spawn` три раза параллельно (в одном блоке tool calls):

```
sessions_spawn({ task: "<промпт Big Mind Mapping>", model: "light", mode: "run", label: "big-mind-mapping" })
sessions_spawn({ task: "<промпт SCAMPER>", model: "light", mode: "run", label: "scamper" })
sessions_spawn({ task: "<промпт Role Storming>", model: "light", mode: "run", label: "role-storming" })
```

Затем вызови `sessions_yield` чтобы дождаться результатов.

**Шаг 2 — синтез:**

```
sessions_spawn({ task: "<промпт синтеза с результатами>", model: "high", mode: "run", label: "synthesis" })
sessions_yield()
```

**Шаг 3 — вывод результата пользователю.**

## Полный цикл (пресет `all`)

1. 6 параллельных `sessions_spawn` (model: light)
2. `sessions_yield` — ждём все результаты
3. 1 синтезирующий `sessions_spawn` (model: high)
4. `sessions_yield` — ждём синтез
5. Показываем итоговый отчёт

Итого: **7 субагентов** (6 методологий + 1 синтез).

## Важные правила

- Все методологические субагенты запускаются **одним блоком** (параллельно)
- `sessions_yield` вызывается **один раз** после всех запусков
- Синтез запускается **только после** получения всех результатов
- Если субагент вернул ошибку — включи это в синтез, не останавливай процесс
- Промпты методологий — в [methodologies.md](methodologies.md)
