# Goals Integration

Use the current goal files supplied by the run context.

## Read Order

1. `goals/3-weekly.md`
2. `goals/2-monthly.md`
3. current yearly goals file

## Alignment Logic

Ask in this order:
1. Does it directly move the current `ONE Big Thing`?
2. If not, does it clearly advance one of the current monthly priorities?
3. If not, does it still build the current yearly direction?
4. If none of the above is true, mark it as `operational`.

Prefer the closest real goal, not the most flattering interpretation.
If the relationship is weak or decorative, do not force goal alignment.

## Priority Effect

Goal alignment may increase priority, but only when the item is also real execution work.

## Linking Rules

When a saved thought clearly supports a goal:
- add a specific goal link,
- use the closest real section or note,
- and avoid decorative goal references.

## Activity Rules

Treat a goal as `active` only when there is real recent movement in at least one of:
- active Todoist tasks,
- recently completed tasks,
- recent daily/summary notes.

Treat a goal as `quiet` when it still matters but current evidence is thin.
Treat it as `stale` when the current cycle shows no meaningful movement at all.
