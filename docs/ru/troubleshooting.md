# Устранение неполадок

[English](../en/troubleshooting.md) | [Оглавление документации](../index.md)

Начинайте каждую проверку из каталога экземпляра:

```bash
a-second-brain doctor
```

Используйте `--smoke` только после успешных обычных проверок.

## Как читать вывод doctor

| Уровень | Действие |
|---|---|
| `ERR` | Устраните до запуска или включения сервисов |
| `WARN` | Проверьте; если ошибок нет, команда всё равно завершится успешно |
| `INFO` | Необязательная функция отключена или недоступна |
| `OK` | Проверка пройдена |

Итоговый код завершения равен `1`, если есть хотя бы одно сообщение `ERR`.

## `.env is missing`

Запустите инициализацию в нужном экземпляре:

```bash
a-second-brain init /path/to/instance
```

Если vault уже существует, не запускайте инициализацию повторно. Восстановите
или создайте только `.env` на основе `.env.example`, затем назначьте права
`0600`.

## Отсутствует обязательная переменная

Отредактируйте `.env`; не экспортируйте секреты в историю shell. Обязательны
`TELEGRAM_BOT_TOKEN`, `DEEPGRAM_API_KEY` и положительный
`OWNER_TELEGRAM_ID`.

## Права `.env` равны 644

Ограничьте доступ:

```bash
chmod 600 .env
```

Диагностика считает это предупреждением, поскольку сами права ещё не
доказывают утечку, однако исправить их следует немедленно.

## `VAULT_PATH does not match ... memory_root`

Стандартный manifest указывает `vault`. Задайте:

```dotenv
VAULT_PATH=./vault
```

Для нестандартной структуры нужен согласованный manifest; сам vault должен
оставаться внутри каталога экземпляра.

## AI CLI отсутствует или авторизация не подтверждена

Установите команду, выбранную в `AI_CLI`, выполните вход и повторите:

```bash
a-second-brain doctor --smoke
```

Проверка авторизации намеренно консервативна. Если вход выполнен, но `doctor`
продолжает предупреждать, проверьте собственную status-команду CLI и окружение
той же учётной записи, от которой работает systemd.

## Не хватает зависимостей Todoist

Если задан `TODOIST_API_KEY`, обязательны и `mcp-cli`, и `npx`. Установите их
для учётной записи сервиса либо очистите ключ, чтобы отключить Todoist.

## Бот сразу завершается

Запустите его в foreground:

```bash
uv run --frozen --no-dev a-second-brain run
```

Затем проверьте:

```bash
journalctl --user -u a-second-brain.service -n 200 --no-pager
systemctl --user show a-second-brain.service \
  -p ExecMainStatus -p ExecMainStartTimestamp
```

Типовые причины: неверные токены, отсутствующая авторизация AI CLI,
недоступный путь vault и различия между окружением сервиса и интерактивным
shell.

## Таймер не сработал

```bash
systemctl --user list-timers 'a-second-brain-*'
journalctl --user -u a-second-brain-process.service --since yesterday
```

Проверьте часовой пояс хоста, включён ли lingering и не завершилось ли ошибкой
резервное копирование перед обработкой.

## Результаты поиска устарели

Запустите обслуживание QMD и проверьте вывод:

```bash
uv run --frozen --no-dev a-second-brain qmd cleanup
```

QMD содержит производные данные. Не редактируйте индекс вместо исправления
Markdown-файлов vault.

## Перед обращением за помощью

Подготовьте:

- обезличенный вывод `doctor`;
- состояние сервиса и таймеров;
- относящиеся к ошибке строки journal с удалёнными личными данными;
- версию пакета и операционную систему;
- точную команду и код завершения.

Никогда не прикладывайте `.env`, заполненный vault, необработанные
расшифровки или логи без удаления чувствительных данных.
