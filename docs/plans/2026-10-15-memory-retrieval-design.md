# Четыре доработки памяти

Статус: реализовано, профильные и общие проверки завершены.

Согласовано владельцем: реализовать четыре пробела из проверки OpenViking.
Сохраняем Markdown, QMD и существующие циклы; без новых сервисов и режимов.

1. Для обзорных вопросов передавать краткий каталог вместо полных compiled-
   страниц. Агент открывает нужные карточки; каталог не считается прочитанным
   содержимым страниц. Точные и статусные вопросы сохраняют текущий путь.
2. Добавить область QMD из путей файлов/каталогов. Ограничивать кандидатов
   перед отбором лучших, в локальном и внешнем поиске. Для однозначно
   названного проекта использовать его карточку и записанные источники;
   при недостатке результатов расширять автоматический поиск.
3. Показывать собранные изменения и замену прежнего факта в существующем
   дайджесте, сохранив ограничения объёма.
4. Дополнять лексический подбор уроков поиском QMD только по каталогу уроков.
   Условия, исключения и подтверждённые источники сохраняются.

Проверки: обзор без полных страниц; точный вопрос по прежнему пути;
посторонние документы не вытесняют проектные; расширение области при нехватке;
в дайджесте видны новые факты и замена; переформулированный запрос находит
урок, сбой поиска не ломает обычный ответ.

Коммиты, перезапуск сервисов и обработка рабочего vault не входят в задачу.

Проверено: 2221 тест прошёл с TERM=dumb; тест установки без привилегий
исключён при запуске от root. Последние уточнения расширения области проверены
отдельно: 25 тестов прошли. Ruff, mypy и git diff --check успешны.
