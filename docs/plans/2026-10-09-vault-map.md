# Компактная HTML-карта знаний

Согласованный результат: самостоятельный HTML без полных текстов заметок,
доступный через меню Telegram. Работает локально без vault и интернета.

## Реализация

- `services/vault_map.py` использует существующий анализатор wikilinks.
- В HTML входят только названия, пути, описания и разрешённые связи.
- `resources/vault_map.html` содержит дерево папок, поиск по метаданным,
  карточку заметки, граф её соседей и полные списки входящих/исходящих ссылок.
- Для читаемости граф показывает до 36 соседей; при большем количестве
  сообщает об этом. Списки ссылок не сокращаются.
- Файл сохраняется как `vault/attachments/vault-map.html` и заменяется
  при обновлении графа. Никаких новых служб или расписаний.
- `/menu` → «Ещё» → «Карта знаний · HTML»: собирает свежий снимок и отправляет
  его документом в тот же чат. Обработка выполняется вне основного цикла бота.
- Внешние библиотеки, шрифты, запросы и вложения HTML не использует.

## Проверка

97 профильных тестов прошли, Ruff и mypy всего src проходят.
В Chromium проверены локальное открытие без сети, поиск, переходы по спискам
и графу, отображение описаний как текста, ширина экрана 390 px.
На рабочем vault файл занимает около 1,59 МБ, сборка занимает около 6 секунд.
Реальная отправка в Telegram не проверена; служба не перезапускалась.
