# Проверка промптов проекта

## Объём и порядок

Проверяем действующие промпты продукта вместе с загружаемыми фазами и
справочниками. Один отдельный сабагент анализирует один логический промпт.
Вспомогательные части его контекста проверяются тем же агентом. Общие навыки,
не вызываемые продуктом, и личные сторонние навыки не являются промптами продукта.

1. Составить каталог вызовов и источников промптов.
2. Для каждого отдельно проверить цель, входные данные, права действий,
   формат результата, соответствие обработчику ответа и противоречия.
3. Главному агенту проверить замечания по коду и оставить только реальные
   дефекты. Внести локальные исправления без изменения архитектуры и режимов.
4. Проверить построение промптов на временных вымышленных данных, выполнить
   профильные тесты и проверки кода, затем независимое ревью изменений.

Критерий готовности: каждый действующий промпт рассмотрен отдельно, подтверждённые
ошибки исправлены, выходные форматы и существующие рабочие процессы сохранены.
Проверки текста промпта не доказывают поведение живой модели; живые внешние
действия, ночная обработка, рестарт, развёртывание и коммиты не входят в работу.

## Результаты

Каждый из 34 действующих промптов проанализирован отдельным сабагентом. Главный агент проверил выводы по построению промпта, входным данным и обработчику ответа. Подключаемые справочники проверены вместе с их потребителями. Независимые итоговые ревью после исправлений не обнаружили ошибок и предупреждений.

## Существенные решения

- Это исправления действующих заданий модели, без новых сервисов, режимов или
  изменения JSON-схем. Текстовые ограничения не являются технической изоляцией
  инструментов и не доказывают поведение каждой модели.
- Исправлено принудительное разрешение неизвестного конфликта при повторе:
  отсутствие новых доказательств теперь позволяет сохранить обе версии явно
  нерешёнными. Это сознательное изменение прежнего поведения промпта.
- Единственная связанная правка обработки фактов: повторное сравнение получает
  явные даты событий и не заменяет текущее утверждение поздно полученным старым
  событием. Даты записей в истории сохраняются в прежнем формате.
- Вкусовые изменения, сокращение всех ответов, новая система оценок качества,
  смена модели и алгоритма поиска не вводились. Существующие чужие локальные
  изменения и предыдущие семь улучшений памяти сохранены.
